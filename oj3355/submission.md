# บันทึกการแก้โจทย์

ไฟล์นี้ต้องเขียนโดยนักศึกษาด้วยคำพูดของตนเอง

ใช้ template นี้เฉพาะกับโจทย์ OJ ที่ถูกระบุว่าต้องส่ง learning log เท่านั้น

ห้ามให้ AI เขียนไฟล์นี้แทนคุณ AI อาจช่วยตรวจ grammar, formatting หรือความชัดเจนได้ หลังจากที่คุณเขียนเนื้อหาของตนเองแล้ว

ถ้าใช้ AI กับโจทย์ learning-log-required นี้ ต้องทำไฟล์ `ai_reflection.md` ด้วย


- ถ้าใช้ทั้ง AI และความช่วยเหลือจากคน ให้นับเฉพาะเวลาที่ทำด้วยตนเองก่อนขอความช่วยเหลือจากภายนอกครั้งแรก ไม่ว่าจะเป็น AI หรือคน
- ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้นับเวลาถึงก่อนเขียน `submission.md`
- ประมาณเวลาได้ แต่ต้องซื่อสัตย์

## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
Input:
ใช้while loopก่อนค่อยรับค่าเข้ามาเป็น int
Output:
เป็นการเขียนแบบย่อ ถ้าเลขเรียงกัน 1,2,3,5 จะเป็น1-3 ถ้าเลขไม่เรียงจะอยู่เดี่ยวๆ 5
Constraints:
ต้องใช้while loopและต้องสร้่างlistว่าง2อัน
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step1:สร้างลิสต์ว่างขึ้นมา
Step2:เข้าwhile loop แล้วรับค่าเข้ามาเป็น int
Step3:ใช้ifเช็ค ถ้าเป็น -1 ให้break
Step4:if not wang:แล้ว return เป็นการป้องกันในกรณีที่เป็น เริ่มมาแล้วเป็น -1 เลยแล้วlistว่าง
Step5:สร้างลิสต์ว่างอีกอัน
Step6: กำหนดfirst = wang[0]และ recent = wang[0] 
Step7:เข้าfor loop
Step8:ใช้if เช็คว่า wang[i] == recent +1 มั้ย
Step9: เข้าelseถ้ามันไม่เท่า
Step10:เช็คว่าfirst == recent: มั้ย ถ้าเท่าก็appendไปในกล่องโดยต้องใช้เป็นstrด้วยเพราะตอนปริ้นเราต้องใช้ .join()
Step11:ถ้าไม่เท่าก็appendค่าแรก + "-" + ตัวเลขล่าสุด
Step12:กำหนดfirst = wang[i]และrecent = wang[i] ีอีกรอบนึง
Step13:ใเช็คว่าfirst == recent: มั้ย ถ้าเท่าก็appendไปในกล่องโดยต้องใช้เป็นstrด้วยเพราะตอนปริ้นเราต้องใช้ .join()
Step14:ถ้าไม่เท่าก็appendค่าแรก + "-" + ตัวเลขล่าสุด
Step15:printแล้วใช้.join()
```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายเหมือนกับแผนแรก  อันดับแรกเราต้องสร้างlistว่างก่อนแล้วค่อยเข้า while loopจากนั้นก็รับค่าเข้ามาเป็นint แล้วเช็คว่า ถ้า== -1ให้break จากนั้นดักกรณีที่ รับค่าเข้ามาแล้วเป็น-1เลยแล้วได้ลิสต์ว่าง จากนั้นก็สร้างlistว่างใหม่เพราะเราต้องเพิ่มค่าใหม่ไปในกล่องนี้่ และตั้งfirst = wang[0]และ recent = wang[0] ก็คือตัวแรกและตัวล่าสุด จากนั้นก็เข้าfor loop เราต้องใช้len(wang)ด้วยเพราะในrangeมันต้องเป็นintเท่านั้น จากนั้นก็เช็คว่า ถ้าwang[i]หรือก็คือเลขที่ตำแหน่ง i  มันเท่ากับrecent +1 เราก็ให้recentเป็นตัวนั้นไปเลย ที่เราต้องบวก1เพราะrecentมันคือตัวล่าสุดหรือก็คือมันจะกระเทิบไปเรื่อยๆ แล้วถ้ามันไม่เท่ากันก็ต้องเข้าelseแล้วเช้คว่าเลขตำแหน่งแรกกับล่าสุดเท่ากันมั้ย ถ้าเท่าก็ให้appendไปเลย อันนี้ก็คือกรณีที่เลขมันเดี่ยวๆไม่ได้เรียง และถ้าไม่เท่าก็ต้องเข้าelse แล้วappendเข้าไป โดยที่เราจะappendเข้าไปเป็นตัวเลขแรกและ "-" ละตัวเลขล่าสุด จากนั้นเราต้องตั้ง first = wang[i]และrecent = wang[i] ใหม่เพราะถ้าสมมติเรามีlist = [1, 2, 3, 8, 9] แล้วเราเช็ค1ถึง3ไปแล้ว แล้ว8จะเช้คต่อก็ไม่ได้เราเลยต้องตั้งขึ้นมาเพื่อเช็คใหม่สำหรับตัวที่เหลือ จากนั้นก้printโดยใช้.join()
```
